# 0077. Folded tile buttons in two rows at every width

Status: Accepted
Date: 2026-11-20
Source: owner, 2026-11-20 («мне так больше нравится, делаем так же на всех разрешениях»)

## Context
ADR 0076 put the four tile buttons in two rows below `xl` only.

## Decision
The 2 × 2 button grid (↑ ↓ / ⧉ ×) is used at every width.

## Consequences
Wide desktop tiles get the same room for the name and look the same as on narrower screens.
