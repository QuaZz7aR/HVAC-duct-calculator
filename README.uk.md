# Калькулятор повітропроводів

[English](README.md) · **Українська**

Веб-калькулятор повітропроводів із листового металу. Ви складаєте перелік фасонних частин вентиляційної системи (прямі повітропроводи, відводи, переходи, трійники, хрестовини, заглушки, врізки) з їхніми розмірами, а калькулятор повертає площу металу кожної позиції, товщину металу за українською нормою, відомість металу за товщинами з кількістю листів до замовлення, площу утеплювача та оцінку вартості за вашими цінами.

**Онлайн:** https://hvac-duct-calculator-rho.vercel.app

Інтерфейс українською за замовчуванням, є англійська версія: перемикач УКР / EN (унизу бічної панелі на комп’ютері, у меню «☰» на телефоні) змінює мову, браузер запам’ятовує вибір. Інструмент створено для проєктувальників вентиляції та цехів, що виготовляють повітропроводи в Україні. Усе рахується в браузері; бекенду немає, проєкт зберігається лише у вашому браузері.

## Що він робить

- **Площа металу кожної позиції.** Розгортка поверхні кожної фасонної частини з її геометрії, із запасом на з'єднання під фланці та коефіцієнтом розкрою для відводів; врізки включають плоске кільце навколо патрубка. Довгі прямі ділянки діляться на ланки (за замовчуванням 3 м круглі, 1,25 м прямокутні, можна змінити), напр. 22,5 м = 7 × 3 м + 1 × 1,5 м. Для переходів, трійників і хрестовин дві цифри: фактична площа і витрата металу (переходи не коротші за 300 мм, трійники без вирізу під врізку); замовлення, листи й ціна йдуть за витратою.
- **Товщина металу.** Береться з таблиці ДБН В.2.5-67:2013, додаток Ц (круглі: за діаметром, прямокутні: за більшою стороною). Як варіант доступна власна таблиця інженера (прямокутні деталі за еквівалентним діаметром, як у його замовленнях). Для кожного відводу, переходу, трійника і хрестовини можна рахувати припуск під фланець на 2, 1 або 0 кінцях.
- **Відомість металу за товщинами.** Площа для кожної товщини, площа до замовлення із запасом (типово 20 %) і кількість листів обраного розміру (1000 × 2000, 1250 × 2500 або 1500 × 3000).
- **Площа утеплювача (бета).** Для кожної позиції обирається матеріал утеплювача (шість з таблиці інженера); зовнішня поверхня шару = геометрія металу, де кожен розмір збільшено на дві товщини шару. Площа кожної позиції, відомість за матеріалами і підсумок. Модель буде уточнено з інженером.
- **Оцінка вартості.** Введіть власну ціну за м² (грн) для кожної товщини металу та матеріалу утеплювача: вартість кожного рядка і разом. Метал рахується від площі до замовлення. Цін за замовчуванням немає.
- **Попередження щодо введених даних.** Незвичні, але допустимі значення (співвідношення сторін від 3 і понад 6,3, сторона понад 2000 мм, великий радіус відводу) позначаються і ніколи не змінюються.
- **Імпорт з Excel або PDF.** Завантажте готову специфікацію (.xlsx, .csv або PDF з текстом, не скан): сайт сам знаходить колонки (код типу або назва, розміри, довжина, кількість, система й номер), розпізнає типи деталей за кодами інженера й за назвами на кшталт «КО 90 Д150», показує кожен рядок і дає обрати тип для тих, яких не знає. Файл читається в браузері й нікуди не завантажується.
- **Нумерація по системах.** Одна кнопка дає позиції «система-номер» (ПВ1-1, ПВ1-2): лише порожнім або всім заново, з попереднім переглядом.
- **Довідка з відео.** «Як користуватися» біля заголовка (кругла «?» на телефоні) проводить через шість кроків, на телефоні через сім, у кожному короткий ролик справжнього інтерфейсу.
- **Експорт.** Результати можна завантажити файлом Excel (специфікація з підсумками, відомість металу за товщинами, відомість утеплювача) або надрукувати чи зберегти в PDF.
- **Зберігається у браузері.** Перелік, його порядок і позиції, параметри та ціни лишаються в цьому браузері між відвідинами (нікуди не надсилаються); «Видалити всі» починає з нуля.
- **Простий і розширений режим.** Простий режим (за замовчуванням) показує лише розміри, кількість і площі металу; розширений додає параметри розрахунку, припуски, утеплювач і ціни. Вибір запам’ятовується в браузері; приховані значення й далі враховуються.
- **Схеми.** Кожна картка деталі показує мініатюру ізометричної схеми; клік відкриває повну схему з літерами розмірів, які використовуються у формі.

## Підтримувані деталі

19 типів, з позначеннями, як в українській специфікації.

В англійському інтерфейсі ті самі типи мають короткі англійські коди (C = circular, R = rectangular): CD, RD повітропроводи; CE, RE відводи; CR, RR, RC переходи; CTap, RTap врізки; CT, CRT, RT, RCT трійники; CX, CRX, RX, RCX хрестовини.

| Група | Типи |
|---|---|
| Прямі повітропроводи | круглий (КПв), прямокутний (ППв) |
| Відводи | круглий (КВд), прямокутний (ПВд), будь-який кут |
| Переходи | круглий (КП), прямокутний (ПП), з прямокутника на круг (ППК) |
| Заглушки | кругла, прямокутна |
| Врізки | кругла (Квр), прямокутна (Пвр) |
| Трійники | круглий (КТ), круглий із прямокутною врізкою (КПТ), прямокутний (ПТ), прямокутний із круглою врізкою (ПКТ) |
| Хрестовини | кругла з круглими врізками (ККХ), кругла з прямокутними врізками (КПХ), прямокутна з прямокутними врізками (ППХ), прямокутна з круглими врізками (ПКХ) |

У трійниках і хрестовинах отвори під відгалуження віднімаються від основного повітропроводу; товщина визначається за основним повітропроводом.

## Як перевірено розрахунки

Еталоном є розрахункова таблиця, якою практикуючий інженер-вентиляційник роками користується на реальних об'єктах. Калькулятор побудовано відповідно до неї, а не лише за її мотивами:

- **Фікстури є джерелом істини.** Очікувані значення лежать у [`src/lib/calc/__fixtures__/`](src/lib/calc/__fixtures__/) і комітяться вручну, окремо від коду. Кожен випадок позначено `basis: 'geometry'` (виведено незалежно, з геометрії) або `basis: 'excel'` (відповідає умовності таблиці). Тести ніколи не підганяються під код.
- **Excel є орієнтиром, а не істиною.** Порядкова перевірка виявила помилки у формулах шаблону. Там, де таблиця помиляється, калькулятор рахує правильне значення, а відхилення задокументовано ([ADR 0001](docs/adr/0001-excel-is-a-reference-not-the-truth.md) та [відомі відхилення](docs/decisions.md)).
- **Відкриті питання йдуть до інженера.** Коефіцієнти без підтвердженого джерела зберігаються в конфігурації з позначкою `TODO(confirm)` і вносяться до реєстру, а не вгадуються. Його відповіді записано в [`docs/engineer-answers.md`](docs/engineer-answers.md).
- **Українські норми.** Товщина та обмеження співвідношення сторін узяті з ДБН В.2.5-67:2013.

Кожне інженерне рішення має окремий запис у [`docs/adr/`](docs/adr/) (контекст, рішення, наслідки, джерело) з покажчиком у [`docs/decisions.md`](docs/decisions.md). Документація проєкту англійською.

## Архітектура

```
src/lib/calc/        чисте ядро на TypeScript: геометрія, товщина, коефіцієнт розкрою, кількість листів,
                     властивості повітря та втрати тиску. Без фреймворку і без бібліотеки валідації.
src/lib/validation/  схеми Zod навколо ядра; помилки є стабільними кодами, а не текстом
src/lib/form/        шар форми: сирий текст -> перевірені дані -> результати; типові значення і попередження
src/lib/i18n/        усі рядки, які бачить користувач (український та англійський словники)
src/components/      компоненти React; лише props, без розрахунків
```

- Одиниці: міліметри, градуси та м³/год на межі, SI всередині ядра, перетворення в одному модулі.
- Одна довжина розгортки на деталь живить усі значення площі, тож дві копії однієї геометрії не можуть розійтися.
- Ядро також рахує втрати тиску (тертя за Альтшулем, місцеві опори, властивості повітря за заданих умов). Поки що їх приховано в інтерфейсі; вони повернуться як окремий аеродинамічний режим.

## Стек

Next.js (App Router), React, TypeScript (strict), Tailwind CSS, Zod, Vitest. Розгорнуто на Vercel з Vercel Web Analytics. CI на GitHub Actions запускає перевірку типів, лінтер і тести для кожного pull request.

## Локальний запуск

Потрібен Node 24 (див. `.nvmrc`).

```bash
npm ci
npm run dev        # http://localhost:3000
npm test           # модульні тести (Vitest)
npm run typecheck
npm run lint
```
